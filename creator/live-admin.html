Link this session to a podcast so listeners can open the show page directly. Each session has its own room, allowing multiple creators to run separate live sessions at the same time.
Live audio engine: This studio now connects the host microphone to LiveKit, using your secure Render token service. Listener and co-host pages must also be migrated to LiveKit before audience audio and guest audio are fully end-to-end. Click START LIVE BROADCAST to connect the host to the LiveKit room. Share the session’s Listener URL and have listeners open it and press Connect. Each session has its own room, so multiple creators can run separate broadcasts at the same time.

Prevent echo: Use headphones on the creator and listener devices. Do not play the broadcast through speakers in the same room as an open microphone; that sound can be picked up and sent back into the stream and recording. Close any other tab or app monitoring the microphone. Browser echo cancellation helps but cannot remove every acoustic feedback situation.

Network note: this version uses direct peer-to-peer connections and public STUN servers; some networks may require a TURN relay, and large audiences are better served by a media server.
