Studio guide · read anytime

How to use the entire studio

Follow these steps from setup to a saved, reviewed export. Nothing is published unless you deliberately create and publish an episode elsewhere.

USER GUIDE

1 · Prepare your session

Give the session and project clear names. Choose a podcast only if you already know where it belongs. Connect headphones, select the microphone, grant browser permission, and run the sound check. Add microphone tracks only for inputs you need.

2 · Record and review

Use Quick record or Start recording. Pause/resume as needed, then Stop & review. Listen to the master and each separate track. Download important originals before leaving; browser recordings can be lost if you clear site data or change devices.

3 · Edit the timeline

Choose Load current take to place captured audio on the timeline. Select a clip to edit its settings; drag clips to reposition, use the playhead and zoom, split at the playhead, and use Undo/Redo. Snap and grid help align edits. The original source tracks are not overwritten.

4 · Save projects and versions

Save project stores an editable project locally in this browser. Save version checkpoint keeps a restore point. Export project backup downloads a portable project file containing audio sources; keep it safe. Import project backup brings that file into the local library. Cloud saving requires sign-in, Supabase configuration, and private-bucket policies.

5 · Finalize and download

Preview the edited arrangement from start to finish. Check levels, clip positions, fades, title and backup. Download final WAV renders the edited timeline as stereo WAV. This can take time and uses browser memory, especially for long sessions.

6 · Private saves vs episode drafts

Save captured audio privately uploads captured source tracks/master to your private recording library; it is not the same as uploading the edited timeline WAV. Add as new episode draft copies a saved master into an unpublished episode draft. Review that draft before any publishing action.

7 · Open, delete and protect work

Open a local or cloud project to continue editing. Delete removes the selected project and associated stored project data; cloud deletion permanently removes that project’s cloud files and versions after confirmation. Export a backup first if you may need it again.

Troubleshooting

If the microphone is missing, allow microphone access and refresh devices; use a secure HTTPS page and a supported browser. If cloud options fail, sign in again and check Supabase config, the private studio-recordings bucket, and per-user storage policies. If WAV export fails, try a shorter timeline or export separate original tracks.
