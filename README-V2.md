# CrowRules Podcasting V2 — Creator Studio

V2 begins with a lightweight Creator Studio on top of the existing V1.0 foundation.

## Added
- Universal CrowRules member/creator ownership checks
- Creator dashboard
- Podcast, episode, play and subscription-plan counters
- Podcast catalog cards
- Direct links to create episodes and manage plans
- Existing Supabase and Stripe architecture retained

## Deliberately deferred
- Resumable 5 GB uploads
- Full analytics
- Webhook lifecycle synchronization
- Payout dashboard
- Moderation queue
- Scheduled publishing UI
- Recommendation engine

The V2 structure is intentionally simple so these can be added without replacing the V1.0 pages.
