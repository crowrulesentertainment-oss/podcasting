Help us identify your challenge entry

1. Choose your event

Thankful Voices or Christmas Voices.

2. Name your entry

Start the episode title with the event name and prompt, for example: “Thankful Voices — Small Things Matter”.

3. Add a description

Include the challenge name, daily prompt, and any context you want listeners to know.

4. Upload in Creator Studio

Choose the UPLOAD MEDIA tab, select your show and media file, and complete the existing upload form.

Publishing note: Creator Studio follows the existing show publishing rules. Uploads to a published show may publish automatically; uploads to an unpublished show remain drafts. Choose the correct show and review its publishing status before uploading. This handoff uploads media as an episode; it does not yet create a separate challenge-entry record or automatically add it to the challenge showcase.
