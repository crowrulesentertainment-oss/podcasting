Configuration checklist

  • Set STRIPE_SECRET_KEY in Supabase secrets. Never put it in HTML.
  • Set APPLICATION_FEE_AMOUNT for the CrowRules application fee in cents.
  • Set PRICE_ID to a recurring Price for the subscription demo.
  • Set STRIPE_WEBHOOK_SECRET on the webhook function.
  • Enable Stripe Connect for the CrowRules platform.
